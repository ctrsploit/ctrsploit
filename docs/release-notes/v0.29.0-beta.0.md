# v0.29.0-beta.0: cve-2021-30465 runc mount TOCTOU escape

Changes since `v0.28.0`.

## Vul

### [cve-2021-30465](https://github.com/ctrsploit/ctrsploit/blob/v0.29.0-beta.0/vul/cve-2021-30465/README.md) ([#397], [#398])

Aliases: `30465`.

New:

- Adds the cve-2021-30465 module: container escape via runc's mount
  destination TOCTOU on runc < v1.0.0-rc95. runc resolves each mount
  destination with `securejoin.SecureJoin` (the check) and mounts it later
  (the use); when the destination lives in a volume shared with an
  attacker-controlled container, racing a symlink exchange inside that
  window makes runc mount outside the container rootfs, and a follow-up
  mount whose source is a subpath of the mounted-over host path
  bind-mounts the host root into the victim.
- Adds `ctrsploit checksec cve-2021-30465` (alias `30465`), also reachable
  as `ctrsploit vul cve-2021-30465 checksec` and included in
  `ctrsploit checksec auto`. The check reads `runc --version` on the host:
  a "vulnerable" verdict is a necessary but not sufficient condition — a
  downstream vendor may backport the fix, and exploitability additionally
  requires an attacker-influenceable mount configuration.
- Adds `ctrsploit vul cve-2021-30465 exploit <variant>` (also
  `ctrsploit exploit cve-2021-30465 <variant>`) with four runtime
  variants: `docker` (`d`), `kubernetes` (`k8s`), `podman` (`p`) and
  `cri-o` (`c`). The exploit is the race payload: it runs inside the
  attacker container and exchanges the victim's mount destinations for
  symlinks while the operator/orchestrator starts the victim with the
  crafted mount set. Shared flags: `--base`, `--hijack-dir`, `--targets`,
  `--flippers`, `--secs`. The hidden `... exploit <variant> victim`
  subcommand is the victim-side entry point: it verifies the escape and
  writes a proof file through the escape onto the host filesystem (uid 0,
  host machine-id); the `CTRSPLOIT_30465_ATTEMPT` env var suffixes the
  proof filename per attempt so repeated or concurrent runs never clobber
  each other's proof.
- docker and kubernetes variants race a blind
  `renameat2(RENAME_EXCHANGE)` loop over the racy bind destinations;
  restart the victim until a win. The kubernetes variant drives
  kubelet-generated `emptyDir` mounts staged at the predictable pod path,
  released with `kubectl set image`.
- podman variant: podman sets `tmpcopyup` on its tmpfs mounts by default,
  so runc's own copy-up is the race window; the racer triggers the
  exchange on the inotify `IN_OPEN` of the filler file, making the first
  victim attempt the expected win.
- cri-o variant: docker-geometry blind race orchestrated with `crictl`;
  `ctrsploit vul cve-2021-30465 exploit crio specs` writes the four CRI
  spec files (`--dir`, `--shared`, `--binary`, `--targets`). cri-o's own
  `read_only` tmpcopyup trio is proven not exploitable (depth-1
  destinations, ordered before the CRI binds) and documented in the cri-o
  README.

Test:

- Adds per-variant e2e against the dqd labs `docker-v20.10.6` (runc
  1.0.0-rc93), `kubernetes-v1.21.1-containerd-v1.5.1` (runc 1.0.0-rc94),
  `podman-v3.0.1` and `cri-o-v1.20.9`, plus unit tests for the shared race
  package and the runc version prerequisite.
