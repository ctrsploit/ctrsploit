# v0.27.1

Changes since `v0.27.0`.

## Vul

### layers subcommand ([#381])

New:

- Adds `layers` subcommand to every pipe-primitive exploit
  (`ctrsploit vul 0847 x layers`, etc.).
- Resolves OCI image configs from remote registries and finds shared
  `diff_ids` across multiple image references.
- Helps identify which files can be cross-container polluted via
  page-cache primitives (Dirty Pipe, Copy Fail, Dirty Frag, etc.).

  ```
  ctrsploit vul 0847 x layers -i golang:1.21-alpine -i golang:1.22-alpine
  ```

Improve:

- Reorders exploit subcommands: `escape` first, then
  `privilege-escalate`, `layers`, `image-pollution`, `clean`.

## Docs

- Moves Build and Progress of Development from root `README.md` to
  `CONTRIBUTING.md` ([#381]).
