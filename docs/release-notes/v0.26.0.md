# Release Notes: v0.26.0

Changes since `v0.25.1`.

## Vul

### cve-2026-31431 ([#362], [#365], [#366])

Aliases: `31431`, `copy-fail`.

New:

- Adds the Copy Fail Linux kernel vulnerability module.
- Adds kernel version prerequisite checks.
- Adds the AF_ALG AEAD 4-byte page-cache write primitive.
- Supports shared pipe-primitive exploit flows:
  - `privilege-escalate`
  - `image-pollution`
  - `clean`
  - `escape exec`
  - `escape image`
  - `escape restart`
- Adds README reproduction steps, vulnerability support list updates, demo
  SVGs, and dqd e2e coverage.
- Documents the pipe-primitive SUID fallback behavior.

Test:

- Adds kernel prerequisite e2e coverage.
- Adds primitive and command-path tests.

### cve-2026-43284 ([#367], [#368])

Aliases: `43284`, `dirty-frag`.

New:

- Adds the Dirty Frag Linux kernel vulnerability module.
- Adds kernel version prerequisite checks.
- Adds the xfrm/ESP 4-byte page-cache write primitive.
- Supports shared pipe-primitive exploit flows:
  - `privilege-escalate`
  - `image-pollution`
  - `clean`
  - `escape exec`
  - `escape image`
  - `escape restart`
- Adds README reproduction steps, usage SVG demos, and dqd e2e coverage.
- Adds explicit e2e result logs for key exploit outcomes.
- Documents the pipe-primitive SUID fallback behavior.
- Includes no-`su` privilege escalation support verified with a dqd e2e case.

Test:

- Adds escape e2e coverage.
- Adds `cve-2026-43284-privilege-escalate-no-su` e2e coverage.
- Verifies the no-`su` fallback returns `uid=0(root)` and leaves
  `/etc/passwd` unchanged.

### cve-2024-40635 ([#359], [#361])

Improve:

- Improves the exploit UID selection.

## Pipe Primitive

### pkg/pipe-primitive ([#362], [#365], [#366], [#368])

New:

- Adds a shared framework for pipe-like page-cache write primitives.
- Adds the common `Primitive` interface used by CVE-specific modules.
- Adds and expands `pkg/pipe-primitive/README.md`.
- Documents shared commands, clean semantics, escape flows, and SUID fallback
  behavior.

### privilege-escalate ([#362], [#368])

New:

- Adds shared local privilege escalation flow.
- Adds SUID helper fallback when `su` and BusyBox `su` are unavailable.
- Runs through a strategy chain:
  - `/etc/passwd` plus `su`
  - SUID helper overwrite fallback
- Passes command stdin/stdout/stderr through to the spawned root shell.
- Checks for a usable `su`-compatible helper before modifying `/etc/passwd`.
- Avoids writing the `/etc/passwd` payload when no `su` route is available.
- Validates root ownership, SUID bit, executable bit, mount `nosuid` status,
  and file size before selecting a SUID overwrite target.

Test:

- Adds tests for fallback strategy selection and combined failure reporting.

### image-pollution ([#362])

New:

- Adds shared container image layer pollution flow.

Test:

- Adds unit coverage for image pollution writes.

### clean ([#366])

New:

- Adds page-cache cleanup by writing to `/proc/sys/vm/drop_caches`.

Test:

- Adds unit coverage for cache-drop behavior.

### escape image ([#362], [#367])

New:

- Adds generated runc overwrite images.
- Supports `start` mode for dynamically linked runc.
- Supports `exec` mode for runc exec capture through a generated
  healthcheck/watcher image.
- Uses Go 1.17 for generated escape image builds.

Test:

- Adds unit coverage for generated image flows.

### escape exec ([#362], [#367])

New:

- Adds runc capture and overwrite through `docker exec`.

### escape restart ([#365], [#367])

New:

- Adds runc capture and overwrite through container restart.
- Supports configurable restart trigger methods.
- Skips duplicate restart loaders.

Test:

- Adds unit coverage for restart loader flows.

### suid-shell-amd64 ([#368])

New:

- Adds an embedded linux/amd64 SUID root shell payload and assembly source.

Test:

- Verified inside a disposable Docker container.

## Env

### services ([#360])

Alias: `svc`.

New:

- Discovers Kubernetes services and ports without API server access.
- Supports `--methods env,wildcard,axfr,cidr`.
- Supports `--cidr`, `--threads`, `--zone`, and `--output`.

Test:

- Adds discovery implementation coverage through package tests.

### suid ([#368])

Alias: `setuid`.

New:

- Finds and lists SUID files visible to the current process.
- Shows path, `ls -l` style mode, owner, size, and usability.
- Supports `--all`, `--path`, and `--skip`.
- Adds `env/suid/README.md`.
- Documents SUID discovery usage and permission formatting.

Test:

- Adds tests for discovery, explicit scan roots, skipped directories, and
  `ls -l` style special permission bits.

### no-new-privs ([#368])

Aliases: `nnp`, `no-new-privilege`, `no-new-privileges`.

New:

- Reads `NoNewPrivs` from `/proc/self/status`.
- Reports whether SUID and file-capability privilege gain is blocked.
- Adds `env/nonewprivs/README.md`.
- Documents NoNewPrivs behavior and aliases.

Test:

- Adds tests for parsing and human-readable result mapping.

### README.md ([#360], [#368])

Improve:

- Adds the new env commands to the top-level env command list.
