# v0.27.0: Kubeconfig User Exec

Changes since `v0.26.1`.

## Vul

### [kubeconfig-user-exec](https://github.com/ctrsploit/ctrsploit/blob/v0.27.0/vul/kubeconfig/user-exec/README.md) ([#380])

Aliases: `user-exec`, `user.exec`, `exec-plugin`.

New:

- Adds a vulnerability module that exploits `users[].user.exec` credential
  plugins in Kubernetes kubeconfig files. `client-go` executes the configured
  `exec.command` before any network request, making an untrusted kubeconfig a
  command-injection vector.
- `ctrsploit vul kubeconfig user-exec exploit -c '<command>'` generates a
  malicious kubeconfig that runs the given command when loaded by a victim's
  `kubectl`.
- Supports `--output` / `-o` to control the output path (default:
  `./malicious-kubeconfig.yaml`).

## Docs

- Rewrites root `README.md` with a vul-first structure: replaces verbose CLI
  help dumps with a Quick Start and component-grouped vulnerability tables
  ([#380]).
