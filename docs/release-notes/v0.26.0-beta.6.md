# Release Notes: v0.26.0-beta.6

Changes since `v0.25.1`.

## Vul

### [cve-2026-31431](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/vul/cve-2026-31431/README.md) ([#362], [#365], [#366], [#369])

Aliases: `31431`, `copy-fail`.

New:

- Adds the Copy Fail Linux kernel vulnerability module.
- Adds kernel version prerequisite checks.
- Adds the AF_ALG AEAD 4-byte page-cache write primitive.
- Supports shared pipe-primitive exploit flows:
  - `privilege-escalate`
  - `image-pollution`
  - `clean`
  - `escape exec`
  - `escape image`
  - `escape restart`
- Adds README reproduction steps, vulnerability support list updates, demo
  SVGs, and dqd e2e coverage.
- Documents the pipe-primitive SUID fallback behavior.
- Adds generated restart-loader material support for repeatable builds.

Test:

- Adds kernel prerequisite e2e coverage.
- Adds primitive and command-path tests.

### [cve-2026-43284](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/vul/cve-2026-43284/README.md) ([#367], [#368], [#369])

Aliases: `43284`, `dirty-frag`.

New:

- Adds the Dirty Frag Linux kernel vulnerability module.
- Adds kernel version prerequisite checks.
- Adds the xfrm/ESP 4-byte page-cache write primitive.
- Supports shared pipe-primitive exploit flows:
  - `privilege-escalate`
  - `image-pollution`
  - `clean`
  - `escape exec`
  - `escape image`
  - `escape restart`
- Adds README reproduction steps, usage SVG demos, and dqd e2e coverage.
- Adds explicit e2e result logs for key exploit outcomes.
- Documents the pipe-primitive SUID fallback behavior.
- Includes no-`su` privilege escalation support verified with a dqd e2e case.
- Adds generated restart-loader material support for repeatable builds.

Test:

- Adds escape e2e coverage.
- Adds `cve-2026-43284-privilege-escalate-no-su` e2e coverage.
- Verifies the no-`su` fallback returns `uid=0(root)` and leaves
  `/etc/passwd` unchanged.

### [cve-2026-43500](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/vul/cve-2026-43500/README.md) ([#369])

Aliases: `43500`, `dirty-frag-rxrpc`, `dirtyfrag-rxrpc`.

New:

- Adds the Dirty Frag RxRPC/rxkad Linux kernel vulnerability module.
- Adds kernel version prerequisite checks.
- Adds `privilege-escalate` support through the RxRPC/rxkad page-cache
  mutation path.
- Adds `image-pollution` support through constrained one-byte-at-a-time
  RxRPC/rxkad decrypt writes.
- Adds `clean` support for page-cache-only exploit effects.
- Supports shared pipe-primitive escape flows:
  - `escape exec`
  - `escape image`
  - `escape restart`
- Adds README reproduction steps and demo SVGs for all exploit flows.
- Marks `video` as supported in the vulnerability status list.
- Adds generated restart-loader material support for repeatable builds.
- Documents why this CVE-specific path is not exposed as a generic
  pipe-primitive arbitrary write.

Test:

- Adds fcrypt/rxkad token layout and command-surface tests.
- Adds kernel prerequisite tests.
- Adds dqd privilege-escalation, image-pollution, clean, and escape e2e
  coverage with explicit result logs.

### [cve-2022-0847](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/vul/cve-2022-0847/README.md) ([#372])

Aliases: `0847`, `dirty-pipe`, `dirtypipe`, `dp`.

New:

- Adds the Dirty Pipe Linux kernel vulnerability module.
- Adds kernel version prerequisite checks for CVE-2022-0847.
- Adds the Dirty Pipe page-cache write primitive.
- Supports shared pipe-primitive exploit flows:
  - `privilege-escalate`
  - `image-pollution`
  - `clean`
  - `escape exec`
  - `escape image`
  - `escape restart`
- Adds Dirty Pipe-specific escape image writer support.
- Adds a Dirty Pipe-specific restart loader for primitives that cannot write
  byte `0`.
- Adds README reproduction steps and demo SVGs for checksec, privilege
  escalation, image pollution, clean, and container escape paths.
- Updates the reproduce environment to download the pre-built ctrsploit release
  in the dqd VM.
- Marks `video` as supported in the vulnerability status list.

Test:

- Adds kernel prerequisite tests.
- Adds Dirty Pipe primitive and command-surface tests.
- Adds dqd e2e coverage for privilege escalation, image pollution, clean,
  `escape exec`, `escape image`, and `escape restart` with explicit result logs.

### [cve-2021-3493](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/vul/cve-2021-3493/README.md) ([#372])

Aliases: `3493`, `ubuntu-overlayfs-pe`.

Improve:

- Moves the legacy CVE-2021-3493 Ubuntu OverlayFS local privilege escalation
  helper into the standard `vul/cve-2021-3493` module path.
- Removes the legacy embedded ELF exploit instead of carrying an opaque binary
  payload into the maintained `vul` module tree.
- Exposes the module through `vul`, `checksec`, and `module kernel` command
  listings.
- Does not expose a top-level `exploit cve-2021-3493` command until a
  maintainable exploit implementation is added.
- Documents that container escape depends on the vulnerable host kernel attack
  surface being reachable from the container.
- Removes the now-empty top-level `helper` command.

Test:

- Adds module metadata, unsupported checksec, and command-surface tests.

## Pipe Primitive

### [pkg/pipe-primitive](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/pkg/pipe-primitive/README.md) ([#362], [#365], [#366], [#368], [#369], [#372])

New:

- Adds a shared framework for pipe-like page-cache write primitives.
- Adds the common `Primitive` interface used by CVE-specific modules.
- Adds `RuncOverwritePayloadProvider` so constrained primitives can provide a
  custom runc overwrite payload.
- Adds and expands `pkg/pipe-primitive/README.md`.
- Documents shared commands, clean semantics, escape flows, and SUID fallback
  behavior.

### helper/pipe-primitive ([#372])

Remove:

- Removes the obsolete helper-level pipe primitive framework.
- Replaces the old helper flow with the maintained `pkg/pipe-primitive`
  package used by current kernel vulnerability modules.

### [privilege-escalate](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/pkg/pipe-primitive/README.md#privilege-escalation) ([#362], [#368], [#369])

New:

- Adds shared local privilege escalation flow.
- Adds SUID helper fallback when `su` and BusyBox `su` are unavailable.
- Runs through a strategy chain:
  - `/etc/passwd` plus `su`
  - SUID helper overwrite fallback
- Passes command stdin/stdout/stderr through to the spawned root shell.
- Checks for a usable `su`-compatible helper before modifying `/etc/passwd`.
- Avoids writing the `/etc/passwd` payload when no `su` route is available.
- Validates root ownership, SUID bit, executable bit, mount `nosuid` status,
  and file size before selecting a SUID overwrite target.

Test:

- Adds tests for fallback strategy selection and combined failure reporting.

### image-pollution ([#362])

New:

- Adds shared container image layer pollution flow.

Test:

- Adds unit coverage for image pollution writes.

### [clean](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/pkg/pipe-primitive/README.md#clean) ([#366])

New:

- Adds page-cache cleanup by writing to `/proc/sys/vm/drop_caches`.

Test:

- Adds unit coverage for cache-drop behavior.

### [escape image](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/pkg/pipe-primitive/README.md#escape-image-writer) ([#362], [#367])

New:

- Adds generated runc overwrite images.
- Supports `start` mode for dynamically linked runc.
- Supports `exec` mode for runc exec capture through a generated
  healthcheck/watcher image.
- Uses Go 1.17 for generated escape image builds.

Test:

- Adds unit coverage for generated image flows.

### escape exec ([#362], [#367], [#372])

New:

- Adds runc capture and overwrite through `docker exec`.

Improve:

- Resolves shebang and argv0-based process entrypoints before overwriting the
  image entrypoint.

Test:

- Adds entrypoint path resolution tests.

### [escape restart](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/pkg/pipe-primitive/README.md#escape-restart-loader) ([#365], [#367])

New:

- Adds runc capture and overwrite through container restart.
- Supports configurable restart trigger methods.
- Skips duplicate restart loaders.

Test:

- Adds unit coverage for restart loader flows.

### runc overwrite ([#372])

New:

- Adds default shell-script runc overwrite payload support.
- Allows CVE-specific primitives to return a custom runc overwrite payload when
  shell-script overwrite is not compatible with the primitive.

Test:

- Adds runc overwrite payload selection tests.

### suid-shell-amd64 ([#368], [#369])

New:

- Adds an embedded linux/amd64 SUID root shell payload, assembly source, and
  generator.

Test:

- Verified inside a disposable Docker container.

### static-shell-amd64 ([#372])

New:

- Adds an embedded linux/amd64 static shell ELF payload and generator for runc
  overwrite paths where a shebang payload is not usable.

Test:

- Adds static shell payload patching tests.

## Env

### [services](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/README.md#env-services) ([#360])

- Supports `--cidr`, `--threads`, `--zone`, and `--output`.

Test:

### [suid](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/env/suid/README.md) ([#368])

Alias: `setuid`.

New:

- Finds and lists SUID files visible to the current process.
- Shows path, `ls -l` style mode, owner, size, and usability.
- Supports `--all`, `--path`, and `--skip`.
- Adds `env/suid/README.md`.
- Documents SUID discovery usage and permission formatting.

Test:

- Adds tests for discovery, explicit scan roots, skipped directories, and
  `ls -l` style special permission bits.

### [no-new-privs](https://github.com/ctrsploit/ctrsploit/blob/v0.26.0-beta.6/env/nonewprivs/README.md) ([#368])

Aliases: `nnp`, `no-new-privilege`, `no-new-privileges`.

New:

- Reads `NoNewPrivs` from `/proc/self/status`.
- Reports whether SUID and file-capability privilege gain is blocked.
- Adds `env/nonewprivs/README.md`.
- Documents NoNewPrivs behavior and aliases.

Test:

- Adds tests for parsing and human-readable result mapping.
