# v0.26.1-beta.1: Fragnesia CVE-2026-46300 and generated module catalog

Changes since `v0.26.0`.

## Vul

### [cve-2026-46300](https://github.com/ctrsploit/ctrsploit/blob/v0.26.1-beta.1/vul/cve-2026-46300/README.md) ([#376], [#378])

Aliases: `46300`, `fragnesia`.

New:

- Adds the Fragnesia Linux kernel vulnerability module for the xfrm
  ESP-in-TCP page-cache write primitive.
- Adds conservative kernel prerequisite checks for CVE-2026-46300.
- Supports shared pipe-primitive exploit flows:
  - `privilege-escalate`
  - `image-pollution`
  - `clean`
  - `escape exec`
  - `escape image`
  - `escape restart`
- Adds Fragnesia-specific escape image writer support.
- Adds a Fragnesia-specific restart loader for `escape restart`.
- Documents Fragnesia's 4096-byte collateral window and the resulting target
  constraints for structured files, image pollution, and runc overwrite flows.
- Adds README reproduction steps for checksec, local privilege escalation,
  image pollution, clean, `escape exec`, generated escape images, and
  `escape restart`.
- Adds the module to the `vul`, `exploit`, `checksec`, and kernel module
  listings.

Test:

- Adds Fragnesia primitive and command-surface tests.
- Adds restart loader patching and execution tests.
- Adds dqd e2e coverage for privilege escalation, image pollution, clean,
  `escape exec`, `escape image`, and `escape restart`.

### README module tables ([#376], [#377])

Improve:

- Adds CVE-2026-46300 to the root README and `vul/README.md` kernel module
  tables.
- Adds maintainer metadata to module README files for generated module catalog
  consumption.

## Pipe Primitive

### escape restart ([#378])

Improve:

- Extends the shared restart escape path with Fragnesia restart loader support.
- Handles Fragnesia's prefix overwrite constraints by writing a compact loader
  and shebang trampoline before triggering container restart.

### escape image ([#378])

Improve:

- Adds Fragnesia extra writer files to generated escape images so the image
  payload can run the CVE-specific page-cache write helper.

## Build

### Makefile generate targets ([#378])

Improve:

- Moves generate-related targets into `make/Makefile.generate`.
- Keeps the top-level `Makefile` focused on including build, docs, generate,
  e2e, and help fragments.
- Adds the CVE-2026-46300 restart-loader generation rule.

### [modules.json](https://github.com/ctrsploit/ctrsploit/blob/v0.26.1-beta.1/modules.json) ([#375], [#377])

New:

- Adds a generated module catalog at `modules.json`.
- Adds `script/update_modules_json.go` for generating the catalog from module
  metadata.
- Adds `script/update_module_maintainers.py` for updating README maintainer
  front matter.

Test:

- Adds module catalog generation tests.
