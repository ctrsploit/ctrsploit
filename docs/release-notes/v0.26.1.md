# v0.26.1: Fragnesia CVE-2026-46300

Changes since `v0.26.0`.

## Highlights

- Adds the Fragnesia Linux kernel module for CVE-2026-46300, with aliases
  `46300` and `fragnesia`.
- Supports vulnerability checks through `ctrsploit checksec cve-2026-46300`
  and `ctrsploit vul 46300 checksec`.
- Supports local privilege escalation and container escape flows through
  `ctrsploit vul 46300 exploit`, including:
  - `privilege-escalate`
  - `image-pollution`
  - `clean`
  - `escape exec`
  - `escape image`
  - `escape restart`
- Adds conservative kernel prerequisite checks for the xfrm ESP-in-TCP
  page-cache write path.
- Adds Fragnesia-specific generated image writer and restart-loader support for
  the shared pipe-primitive escape flows.

## Fixes And Reliability

- Improves `escape restart` reliability by retrying the Fragnesia receiver
  `accept` path when it is interrupted by a signal.
- Documents Fragnesia's 4096-byte collateral write window and the resulting
  constraints for structured files, image pollution, and runc overwrite flows.

## Docs And Demos

- Adds the CVE-2026-46300 README with reproduction steps for checksec,
  privilege escalation, image pollution, clean, `escape exec`, generated escape
  images, and `escape restart`.
- Adds terminal demo SVGs for the CVE-2026-46300 checksec and exploit flows.
- Adds CVE-2026-46300 to the root README, `vul/README.md`, `vul`, `exploit`,
  `checksec`, and kernel module listings.
- Adds `modules.json`, generated module catalog tooling, and maintainer
  metadata used by the catalog.

## Build And Test

- Adds `generate-cve-2026-46300` for Fragnesia payload artifact generation.
- Moves generate-related Makefile targets into `make/Makefile.generate`.
- Adds dqd e2e coverage for CVE-2026-46300 privilege escalation, image
  pollution, clean, `escape exec`, `escape image`, and `escape restart`.
- Adds primitive, command-surface, kernel prerequisite, restart-loader patching,
  and restart-loader execution tests.
