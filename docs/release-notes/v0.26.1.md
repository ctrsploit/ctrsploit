# v0.26.1: Fragnesia CVE-2026-46300

Changes since `v0.26.0`.

## Vul

### [cve-2026-46300](https://github.com/ctrsploit/ctrsploit/blob/v0.26.1/vul/cve-2026-46300/README.md) ([#376], [#378], [#379], [bf1a4d8])

Aliases: `46300`, `fragnesia`.

New:

- Adds the Fragnesia Linux kernel vulnerability module for the xfrm
  ESP-in-TCP page-cache write primitive.
- Supports vulnerability checks through `ctrsploit checksec cve-2026-46300`
  and `ctrsploit vul 46300 checksec`.
- Supports `privilege-escalate`, `image-pollution`, `clean`, `escape exec`,
  `escape image`, and `escape restart`.
- Adds Fragnesia-specific generated image writer and restart-loader support for
  the shared pipe-primitive escape flows.
- Adds README reproduction steps and terminal demo SVGs for the main checksec
  and exploit flows.

Fix:

- Retries the Fragnesia receiver `accept` path when it is interrupted by a
  signal, improving `escape restart` reliability.

Test:

- Adds primitive, command-surface, kernel prerequisite, restart-loader, and dqd
  e2e coverage for CVE-2026-46300.

## Build
